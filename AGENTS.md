# AGENTS.md

## Agent skills

### Issue tracker

Issues live as GitHub issues in `purinkle/radfords`, driven by the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Category and state roles, each label string equal to its name; a triaged issue carries exactly one of each. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
